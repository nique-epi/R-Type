## The game

<CardGrid>
  <Card title="Co-op for four" icon="star">
    Up to four pilots share one screen of the sector, each in their own color, against waves of Bydos and the Bydo Tyrant at the end of the level.
  </Card>
  <Card title="The server decides" icon="setting">
    The server simulates every game at 60 ticks per second. The client predicts its own ship and draws the others from the world states it receives.
  </Card>
  <Card title="Many games, one host" icon="rocket">
    One server runs up to eight games, each in its own process. The master lists the servers so players find a game from the server map.
  </Card>
  <Card title="Built to be modded" icon="puzzle">
    Waves, entity sheets and Luau scripts change the game without recompiling it. A client downloads the content pack of a modded server when it joins.
  </Card>
</CardGrid>
