## Context

A developer who wants a signature, a base class or the members of a struct should not have to open the header. The class reference is generated by Doxygen from the doc comments of the headers in `src/`, and published with this site.

[Open the class reference](/R-Type/api/index.html)

## A complement, not the documentation

The reference lists what the code declares. It does not say why a module exists, how the programs fit together or what a rule protects. Those are the pages of this site: start with the [architecture](/R-Type/architecture/) and the [project layout](/R-Type/project-layout/), and use the reference to look a name up.

## How it is built

| Step | Where |
|---|---|
| Configuration | `docs/Doxyfile`, which reads every `.hpp` and `.tpp` under `src/` |
| Generation | the `docs` workflow runs `doxygen` before the site build |
| Output | `docs/public/api/`, copied by Astro to `/api/` of the site, not committed |

To build it locally, install Doxygen and Graphviz, then:

```bash
cd docs && doxygen Doxyfile
```
